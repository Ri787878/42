### Error Codes:

	- '-20' to '-29' are Parcing errors:
		- '-29' Wrong number of arguments passed;
		- '-22' Argument type is not an int;
		- '-23' Scheduler argument is "fifo" or "edf";
	- '-30' to '-39' are Memory errors:
		- '-30' Expected variable to not be 'NULL', but was 'NULL';
		- '-31'
	- '-40' to '-49' are Validation errors:
		- '-40' Number of coders must be more than 0;
		- '-41' Number of compiles must be more than 0;
		- '-42' Number of time_to_burnout of  must be more than 0;
		- '-43' Number of time_to_compile must be more than 0;
		- '-44' Number of time_to_debug must be more than 0;
		- '-45' Number of time_to_refactor must be more than 0;
		- '-46' Number of dongle_cooldownc must be more than 0;
